### 5. 디지털 가구 분석

#### Why

일상생활 속에서 필요한 다양한 정보를 더욱 쉽고 빠르게 파악하기 위해서이다.

#### What

실내의 유리, 거울 등의 표면이나 다양한 가전·가구가 인터넷에 연결되어 정보를 제공하고 사용자와 상호작용하는 형태이다.

#### How

현재 다양한 가전제품과 가구에 AI와 IoT 기술이 적용되면서 사용자의 행동을 인식하고 자동으로 동작하는 스마트 가구가 개발되고 있다.

#### Next

앞으로 해결해야 할 문제로는 다음과 같은 부분이 있다.

* 서로 다른 가구와 가전제품 간의 연결성 부족
* 제조사마다 다른 플랫폼으로 인한 호환성 문제
* 개인정보 수집 및 보안 문제
* 다양한 기기를 하나의 시스템처럼 자연스럽게 연결할 수 있는 기술 필요
